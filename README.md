## 4. Backend Preview
### 📌 Note

If the server is running correctly, accessing the root path (`/`) will return the following response:

```json
{
  "status": 404,
  "payload": {
    "statusCode": 404,
    "status": "Not Found",
    "message": "not found or GET method not support."
  }
}

```
This response confirms that the backend server is running correctly. The `404 Not Found` occurs because no routes are defined for the root path (`/`). All API endpoints are accessible via `/api/v1`.
